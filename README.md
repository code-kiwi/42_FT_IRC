# ft_irc

This project was developed as part of the École 42 curriculum.

## Objective
The goal of this project is to implement an IRC server in C++, following the IRC protocol
specifications and supporting multiple simultaneous clients.

## Key features
- TCP server handling multiple clients
- Channel management
- User authentication and registration
- Command parsing and execution
- Basic file transfer support through the client

## Client
HexChat was used as the reference IRC client for development and testing.

## Technical stack
- C++
- TCP / sockets
- IRC protocol
- Linux

## Notes
This project focuses on server-side networking, protocol handling, and concurrency.
Bonus features were not implemented, except for file upload handled by the client.
